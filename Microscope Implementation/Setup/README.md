# Zen API Setup

1) Follow the steps in `[installation_instructions.txt](./Installation_instructions.txt)` to set up the Zen API with the microscope

2) Install the MorphoLibJ into fiji by following the instructions found [here](https://imagej.net/plugins/morpholibj#installation)

3)  For the python environment mixing pyimagej and zenapi libraries the requirements are detailed in the `[requirements.txt](./requirements.txt)` file

4) In order for pyimagej to be able to write files onto the disk vscode must be started with administrator privileges.
